Public notes archive of the Algothon 2026 research process.

This repository records:

- major milestones;
- how the strategy ideas evolved;
- the validation and decision-making process;
- lessons that may transfer to future quantitative research.

It intentionally excludes:

- strategy source code or pseudocode that can be directly implemented;
- asset names, selected pairs, exact thresholds, and final parameters;
- price data and derived position or PnL series;
- submission packages, hashes, IDs, and portal receipts;
- local file paths or personal information.
